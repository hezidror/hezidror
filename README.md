# דף נחיתה - חזי | עיצוב שיער

דף נחיתה סטטי (HTML/CSS/JS) לעסק "חזי - עיצוב שיער", בעיצוב שחור-זהב תואם ללוגו, מוכן לפרסום ב-GitHub Pages ולשיתוף ברשתות.

## מה יש כאן
- `index.html` - מבנה הדף (הירו, שירותים, מחירון, גלריה, אודות, שעות פתיחה, יצירת קשר + מפה, כפתור וואטסאפ צף)
- `style.css` - העיצוב (פלטת שחור-זהב לפי הלוגו)
- `script.js` - תפריט מובייל, שנה בפוטר, סימון היום הנוכחי ו"פתוח עכשיו/סגור כרגע" בשעות הפתיחה, ואנימציית הופעה בגלילה
- `assets/logo.jpg` - לוגו הלקוח, מוצג בכותרת העליונה
- `assets/favicon.png` - פוביקון שנחתך מהלוגו
- `assets/og-image.jpg` - תמונת תצוגה מקדימה לשיתוף ברשתות (נחתכה מהלוגו)

## שיתוף ברשתות חברתיות
בדף כבר מוגדרות תגיות Open Graph ו-Twitter Card, כך שכששולחים את הקישור בוואטסאפ, פייסבוק, אינסטגרם (בביו) או טוויטר/X תופיע תצוגה מקדימה עם כותרת, תיאור ותמונה (`assets/og-image.jpg`). חשוב לעדכן את הכתובות בסעיף 5 לפני השיתוף הראשון, אחרת התצוגה המקדימה תצביע לכתובת שגויה. אפשר לבדוק איך התצוגה נראית בכלים כמו [Facebook Sharing Debugger](https://developers.facebook.com/tools/debug/) לאחר הפרסום.

## פרסום ב-GitHub Pages
1. בהגדרות הריפו: Settings → Pages.
2. תחת "Build and deployment", לבחור Source: **Deploy from a branch**.
3. לבחור את ה-branch (`main` או הענף שבו נמצאים הקבצים) ותיקיית root (`/`).
4. לשמור - הדף יהיה זמין בכתובת `https://<username>.github.io/<repo>/`.

אפשר גם לפתוח את `index.html` ישירות בדפדפן כדי לראות תצוגה מקדימה מקומית.
