# אתר - חזי דרור | עיצוב שיער, נתניה

אתר סטטי (HTML/CSS/JS) למספרת נשים וגברים של חזי דרור בנתניה, בעיצוב שחור-זהב תואם ללוגו, מוכן לפרסום ב-GitHub Pages.

## מבנה האתר
אתר של עמוד אחד שגוללים בו לפי הסדר. הקישורים בתפריט, בכרטיסים "עיצוב שיער לכל אחד ואחת" ובפוטר קופצים לחלק המתאים, והתפריט מסמן את החלק שנמצאים בו.

סדר החלקים ב-`index.html`:
1. כותרת עם הלוגו ברקע וכפתורי קביעת תור (`#top`)
2. פס 4 יתרונות
3. האיש מאחורי המספריים (`#about`)
4. הסיפור מאחורי המספרה (`#story`)
5. עיצוב שיער לכל אחד ואחת - כרטיסים לגברים/נשים/מוצרים (`#services`)
6. עיצוב שיער לגברים - שירותים וגלריה (`#men`)
7. עיצוב שיער לנשים - למה כדאי להיות לקוחה אצלי וגלריה (`#women`)
8. המוצרים שלנו - גלריה (`#products`)
9. שעות פתיחה (`#hours`) ויצירת קשר + מפה (`#contact`)

## קבצים
- `_data/content.yml` - **כל התוכן**: טקסטים, תמונות, גלריות, שעות פתיחה ופרטי קשר
- `index.html` - התבנית שבונה את הדף מתוך `content.yml` (GitHub Pages בונה אותה אוטומטית עם Jekyll)
- `_includes/` - חלקים חוזרים בתבנית (גלריה, כרטיסים, כפתורי קביעת תור)
- `style.css` - העיצוב (פלטת שחור-זהב לפי הלוגו)
- `script.js` - תפריט מובייל, סימון החלק הנוכחי בתפריט, "פתוח עכשיו/סגור כרגע", תצוגת תמונות מוגדלת בגלריות ואנימציית הופעה בגלילה
- `assets/uploads/` - כל התמונות של התוכן (תמונות שמעלים ממסך הניהול נשמרות כאן)
- `assets/` - לוגו, פוביקון ותמונת שיתוף
- `.pages.yml` - הגדרות מסך הניהול (Pages CMS)

## עריכת האתר בעצמך - מסך ניהול
האתר מתחבר ל-**Pages CMS**, מסך ניהול חינמי לאתרים ב-GitHub. הכניסה היא עם חשבון ה-GitHub, כך שרק מי שיש לו הרשאה לריפו יכול לערוך.

**חיבור ראשוני (פעם אחת):**
1. להפעיל GitHub Pages (ראו "פרסום ב-GitHub Pages" למטה).
2. להיכנס ל-https://app.pagescms.org וללחוץ **Sign in with GitHub**.
3. לאשר את ההתקנה של Pages CMS על הריפו `hezidror` (אפשר לבחור רק את הריפו הזה).
4. לבחור את הריפו ואת הענף שממנו האתר מתפרסם.

**עריכה:**
- נכנסים ל-https://app.pagescms.org, בוחרים את הריפו ולוחצים על **תוכן האתר**.
- כל חלק באתר מופיע כקבוצת שדות עם שם בעברית (כותרת ראשית, האיש מאחורי המספריים, גלריה ועוד).
- כדי להחליף תמונה - לוחצים על שדה התמונה ומעלים תמונה חדשה. בגלריות אפשר להוסיף, למחוק ולשנות סדר.
- לוחצים **Save**. האתר מתעדכן אוטומטית תוך דקה-שתיים.
- כל שמירה נשמרת בהיסטוריה של GitHub, כך שתמיד אפשר לחזור לגרסה קודמת.

**טיפים לתמונות:** עדיף תמונה לאורך (עומדת) לגלריות, ברוחב של עד כ-1500 פיקסלים. תמונות גדולות מאוד מאטות את האתר.

## להשלים (מסומן באתר ב-✏️ או "📷 תמונה בקרוב")
אפשר להשלים הכל ממסך הניהול, או ישירות ב-`_data/content.yml`:
1. **פירוט השירותים לגברים** - בשדה "עיצוב שיער לגברים" → "שירותים".
2. **למה כדאי להיות לקוחה אצלי** - בשדה "עיצוב שיער לנשים".
3. **גלריית גברים וגלריית מוצרים** - להעלות תמונות.
4. **אינסטגרם / פייסבוק** - בשדה "פרטי קשר" (שדה ריק מסתיר את הכפתור).

כתובת האתר בתגיות השיתוף (Open Graph) נקבעת אוטומטית על ידי GitHub Pages.

## פרסום ב-GitHub Pages
1. בהגדרות הריפו: Settings → Pages.
2. תחת "Build and deployment", לבחור Source: **Deploy from a branch**.
3. לבחור את ה-branch ותיקיית root (`/`).
4. לשמור - האתר יהיה זמין בכתובת `https://<username>.github.io/<repo>/`.

הדף נבנה על ידי GitHub Pages, ולכן פתיחה ישירה של `index.html` מהמחשב תציג את התבנית ולא את האתר. לתצוגה מקומית: `jekyll serve` (מתוך תיקיית הריפו).

## חיבור דומיין
ב-Settings → Pages → Custom domain מזינים את הדומיין, ואצל רשם הדומיין מוסיפים רשומת CNAME ל-`www` שמצביעה ל-`<username>.github.io`, וארבע רשומות A לדומיין עצמו: `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`. אחרי שה-DNS מתעדכן מסמנים Enforce HTTPS.
