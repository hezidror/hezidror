# אתר - חזי דרור | עיצוב שיער, נתניה

אתר סטטי (HTML/CSS/JS) למספרת נשים וגברים של חזי דרור בנתניה, בעיצוב שחור-זהב תואם ללוגו, מוכן לפרסום ב-GitHub Pages.

## העמודים
- `index.html` - דף ראשי: כותרת עם השתקפות ולוגו ברקע, כפתורי קביעת תור (וואטסאפ / טלפון), פס של 4 יתרונות, "האיש מאחורי המספריים", קישורים לעמודי הגברים/הנשים/המוצרים, "הסיפור מאחורי המספרה", שעות פתיחה ויצירת קשר + מפה
- `men.html` - עיצוב שיער לגברים: שירותים וגלריה
- `women.html` - עיצוב שיער לנשים: "למה כדאי להיות לקוחה אצלי" וגלריה
- `products.html` - המוצרים שלנו: גלריית מוצרים
- `style.css` - העיצוב (פלטת שחור-זהב לפי הלוגו)
- `script.js` - תפריט מובייל, שנה בפוטר, "פתוח עכשיו/סגור כרגע" בשעות הפתיחה, ואנימציית הופעה בגלילה
- `assets/` - לוגו, פוביקון ותמונת שיתוף

הכותרת, התפריט והפוטר מופיעים בכל אחד מארבעת העמודים - שינוי בהם צריך להיעשות בכל העמודים.

## להשלים (מסומן באתר ב-✏️ או "📷 תמונה בקרוב")
1. **תמונה ראשית בדף הראשי** - `assets/hero-logo.jpg` (הלוגו במסגרת). מוצגת כרקע מאחורי הכיתוב (מוגדר ב-`.hero-bg` ב-`style.css`). להחלפה: לשמור תמונה חדשה באותו שם.
2. **התמונה של חזי** - בסעיף "האיש מאחורי המספריים" ב-`index.html` (להחליף את ה-`div` עם `photo-placeholder` בתגית `<img>`).
3. **הסיפור מאחורי המספרה** - שלושה חלקים ב-`index.html` (איך הכל התחיל / החזון שלי / מה מחכה לך במספרה), ושתי תמונות בצדדים (`story-photo`).
   - **פס היתרונות** (4 אייקונים מתחת לכותרת הראשית) - נוסח מוצע, לעדכן לפי הצורך.
   - **כמה מילים על חזי** - בתיבה המסגרת ב"האיש מאחורי המספריים".
4. **פירוט השירותים לגברים** - ב-`men.html`.
5. **למה כדאי להיות לקוחה אצלי** - שלוש סיבות ב-`women.html`.
6. **גלריות** - בכל `gallery-item` להחליף את `<span>📷 תמונה בקרוב</span>` ב-`<img src="assets/..." alt="...">` (בגברים, בנשים ובמוצרים).
7. **כתובת** - "רחוב הדוגמה 1, נתניה", וגם בקישור הוויז ובמפה (פרמטר `q=`, בקידוד URL).
8. **שעות פתיחה** - בפורמט `09:00 - 20:00` או `סגור`. "פתוח עכשיו" מחושב מהן אוטומטית.
9. **אינסטגרם / פייסבוק** - להחליף את `your_salon`.
10. **כתובת האתר לשיתוף** - להחליף את `https://your-username.github.io/your-repo/` בתגיות `og:` ו-`twitter:` בכל העמודים.

## פרסום ב-GitHub Pages
1. בהגדרות הריפו: Settings → Pages.
2. תחת "Build and deployment", לבחור Source: **Deploy from a branch**.
3. לבחור את ה-branch ותיקיית root (`/`).
4. לשמור - האתר יהיה זמין בכתובת `https://<username>.github.io/<repo>/`.

## חיבור דומיין
ב-Settings → Pages → Custom domain מזינים את הדומיין, ואצל רשם הדומיין מוסיפים רשומת CNAME ל-`www` שמצביעה ל-`<username>.github.io`, וארבע רשומות A לדומיין עצמו: `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`. אחרי שה-DNS מתעדכן מסמנים Enforce HTTPS.
