# דף נחיתה - המספרה שלי

דף נחיתה סטטי (HTML/CSS/JS) למספרה, מוכן לפרסום ב-GitHub Pages.

## מה יש כאן
- `index.html` - מבנה הדף (הירו, שירותים, גלריה, אודות, יצירת קשר)
- `style.css` - העיצוב
- `script.js` - תפריט מובייל ושנה בפוטר
- `assets/` - תיקייה לתמונות

## לפני הפרסום - להחליף:
1. **שם המספרה** - בכל מקום שכתוב "המספרה שלי" ב-`index.html`.
2. **מספר וואטסאפ** - להחליף את `972500000000` בקישורי ה-WhatsApp (בפורמט בינלאומי בלי `+` וללא אפסים מובילים).
3. **מספר טלפון** - להחליף את `+972500000000` בקישורי ה-`tel:`.
4. **קישורי אינסטגרם/פייסבוק** - להחליף את `your_salon` בשם המשתמש האמיתי.
5. **כתובת** - להחליף את "רחוב הדוגמה 1, העיר שלך".
6. **תמונות** - להוסיף תמונות אמיתיות לתיקיית `assets/` ולהחליף את התאים הריקים בגלריה ואת תמונת "אודות" (כרגע רקעים בצבע).

## פרסום ב-GitHub Pages
1. בהגדרות הריפו: Settings → Pages.
2. תחת "Build and deployment", לבחור Source: **Deploy from a branch**.
3. לבחור את ה-branch (`main` או הענף שבו נמצאים הקבצים) ותיקיית root (`/`).
4. לשמור - הדף יהיה זמין בכתובת `https://<username>.github.io/<repo>/`.

אפשר גם לפתוח את `index.html` ישירות בדפדפן כדי לראות תצוגה מקדימה מקומית.
